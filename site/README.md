# AI Lab · 충북대학교 인공지능 연구실

기존 연구실 웹사이트의 실제 콘텐츠를 새 디자인에 적용한 웹사이트입니다.
화면만 확인할 때는 정적 웹서버로 열 수 있고, 세미나 자료실까지 사용하려면 프로젝트 루트의 Docker Compose 서비스를 실행합니다.

- `js/data.js`: 연구실 소개, 구성원, 연구 성과, 연구 이력, 소식, 강의, 한·영 UI 문구.
- `js/main.js`: 화면 렌더링, 한·영 전환, 메뉴, 검색과 필터.
- `js/hero3d.js`: 외부 라이브러리 없이 표시하는 입체 곡면 애니메이션.
- `css/styles.css`: 반응형 레이아웃과 스타일.
- `seminars.html`: Teams/Hermes가 올린 자료를 업로드 날짜 최신순으로 표시하는 세미나 자료실.
- `assets/`: 교수 사진, 약도, 파비콘.

연구 성과 260건, 졸업·수료 기록 24명, 원본 연구원 명단 5명, 연구 이력 24건, 강의 링크 192개를 수록합니다. 구성원 명단은 원본의 2021년 기록이며 현재 소속을 새로 확인한 것은 아닙니다. 외부 강의 영상 서버의 재생 가능 여부도 확인하지 않았습니다.

자세한 출처·제외 범위와 이관 스크립트는 `../migration/README.md`를 참고하세요.

로컬 실행 예:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

세미나 자동 수집과 서버 배포는 `../docs/teams-integration.md`를 참고하세요. 내용 수정 후 브라우저 캐시가 남으면 HTML의 JS/CSS `?v=` 값을 올려주세요.
