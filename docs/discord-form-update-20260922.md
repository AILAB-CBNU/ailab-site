# Discord 버튼·입력 창 업데이트 · 2026-09-22

이제 **파일 업로드 → 봇의 ‘세미나 정보 입력’ 버튼 → 제목·발표일·요약 제출** 순서로 세미나 자료를 등록할 수 있습니다. 입력 창은 Discord 안에서 열리며, 파일을 올린 사람만 사용할 수 있습니다.

## 기존 Windows 서버에 한 번 적용

**12번 홈페이지 업데이트만으로는 적용되지 않습니다.** 이번 ZIP에는 홈페이지와 함께 새 Discord 수집기·Gateway 모듈이 포함됩니다. 기존 구성원 사진·링크 관리와 세미나 삭제 기능도 포함합니다.

1. 자동 업데이트를 사용 중이면 **13-STOP-AUTO-UPDATE.bat**로 잠시 해제합니다.
2. 실행 중인 **06번 홈페이지 창과 10번 Discord 수집기 창을 닫습니다.**
3. **ailab-discord-form-update-20260922.zip**을 기존 프로젝트 폴더 안에 압축 해제하고 같은 이름의 파일을 덮어씁니다. 압축 안의 `site`, `discord_sync`, `seminar_service`, `docs` 폴더가 기존 **06-START-HTTPS-WEBSITE.bat**와 같은 위치에 있어야 합니다.
4. Discord 봇의 세미나-자료 채널 권한에 **채널 보기·메시지 기록 보기·메시지 보내기**가 있는지 확인합니다.
5. Discord 개발자 포털에서 **Message Content Intent**를 켜고, **Interactions Endpoint URL**은 빈칸으로 둡니다.
6. **06-START-HTTPS-WEBSITE.bat**, **10-START-DISCORD-SYNC.bat**를 다시 실행합니다.
7. 1번에서 자동 업데이트를 해제했다면 **11-INSTALL-AUTO-UPDATE.bat**로 다시 등록합니다.
8. 홈페이지는 `Ctrl + F5`로 새로고침합니다. 세미나-자료 채널에 새 파일을 올려 아래 순서로 확인합니다.

**기존 토큰, 체크포인트, 관리자 비밀번호, 업로드한 자료와 사진은 그대로 유지됩니다.** 09번 봇 설정을 다시 하거나 토큰을 새로 발급할 필요가 없습니다. 기존 Python 런타임을 사용하고 WebSocket 모듈도 포함되어 있어 pip·Python·Docker 설치가 필요 없습니다. 기존 10번 실행 파일을 그대로 사용하며 새 인바운드 포트도 열지 않습니다.

## 처음 확인할 동작

1. 세미나-자료 채널에 PDF 등 파일을 첨부해 전송합니다. 본문은 비워 두어도 됩니다.
2. 약 15초 이내에 봇이 답장하면 **세미나 정보 입력**을 누릅니다.
3. 제목, 발표일(`2026-09-22` 형태), 요약을 입력하고 제출합니다. 요약은 여러 줄로 작성할 수 있습니다.
4. 등록 요청이 접수되었다는 안내를 확인한 뒤 홈페이지 `/seminars.html`을 새로고침합니다. 06번 홈페이지가 실행 중이면 잠시 후 반영됩니다. 꺼져 있으면 서버 실행까지 대기합니다.

입력 조건은 제목 1~180자, 요약 1~1,000자, 실제 달력에 있는 `YYYY-MM-DD` 날짜입니다. 발표자는 파일 업로더의 Discord 서버 닉네임이고, 정렬 기준은 원본 파일 메시지의 업로드 날짜입니다.

모든 구성원이 사용할 수 있지만 다른 사람이 올린 자료의 입력 버튼은 사용할 수 없습니다. 잘못 등록한 자료는 **홈페이지 관리자 → 세미나 자료 관리 → 자료 삭제 → 삭제 확인**에서 지웁니다.

## 버튼 없이 기존 양식 사용

아래 본문과 파일을 같은 새 메시지로 보내는 방식도 계속 지원합니다.

```text
# 세미나
제목: 시계열 예측 모델의 이해
발표일: 2026-09-22
요약: 모델 구조와 실험 결과를 소개합니다.
```

기존 `#세미나`도 허용됩니다. 본문 양식은 제목·발표일·요약을 각각 한 줄로 작성하고, 여러 줄 요약은 입력 창에서 사용합니다. 전체 파일 형식·권한·문제 해결은 [Discord 세미나 자료 자동 등록](discord-setup.md)을 확인하세요.

## 배포 내용

이 ZIP은 공개 홈페이지 파일, 지정된 프로그램 소스, 동봉한 WebSocket 라이브러리와 라이선스, 사용 안내만 포함합니다. `runtime/`, `discord-sync-state/`, `seminar-data/`, `seminar-inbox/`, 개인 설정·키 파일은 포함하지 않습니다. 전체 설치 폴더를 새로 만드는 패키지가 아니라 **기존 무설치 서버에 덮어쓰는 업데이트**입니다.
