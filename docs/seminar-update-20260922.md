# 세미나 자료실 업데이트 · 2026-09-22

이번 업데이트는 구성원·소식·과제 안내와 세미나 화면을 갱신하고, Discord 게시 양식 검사와 관리자 자료 삭제 기능을 추가합니다.

기존 11번 자동 업데이트와 12번 즉시 업데이트는 `site/` 화면 파일만 갱신합니다. **게시 양식 검사와 자료 삭제 기능은 이 추가 패키지를 서버 PC에 한 번 적용해야 동작합니다.** 새 Python이나 Docker를 설치할 필요는 없습니다.

## 기존 Windows 서버에 적용

1. 자동 업데이트를 사용 중이면 `13-STOP-AUTO-UPDATE.bat`를 실행해 업데이트 작업을 잠시 해제합니다. 화면 파일을 동시에 바꾸지 않도록 권장하는 절차입니다.
2. 실행 중인 **06번 홈페이지 서버 창과 10번 Discord 수집 창을 닫습니다.** 적용 중에는 홈페이지와 수집이 잠시 중단됩니다.
3. `ailab-seminar-update-20260922.zip`을 **기존 프로젝트 폴더 안에** 압축 해제하고, 같은 이름의 파일은 덮어씁니다. `site`, `discord_sync`, `seminar_service`, `docs` 폴더가 기존 `06-START-HTTPS-WEBSITE.bat`와 같은 위치에 있어야 합니다. 새 하위 폴더 안에 따로 풀지 마세요.
4. `06-START-HTTPS-WEBSITE.bat`와 `10-START-DISCORD-SYNC.bat`를 다시 실행합니다.
5. 1번에서 자동 업데이트를 해제했다면 `11-INSTALL-AUTO-UPDATE.bat`로 다시 등록합니다.
6. 브라우저에서 `Ctrl + F5`로 새로고침하고 관리자 메뉴의 **세미나 자료 관리**가 보이는지 확인합니다. 아래 양식과 파일로 새 메시지를 올리면 보통 15~20초 뒤 자료실에 표시됩니다.

패키지에는 공개 화면 파일과 필요한 프로그램·안내 문서만 들어 있습니다. 기존 Discord 토큰, 수집 체크포인트, 관리자 비밀번호, 세미나 자료와 런타임을 덮어쓰지 않습니다. `09-SETUP-DISCORD.bat`를 다시 실행할 필요도 없습니다.

## Discord에 올릴 양식

지정된 **세미나-자료** 채널에 다음 본문과 파일을 **하나의 새 메시지**로 올립니다. 제목·발표일·요약은 각각 한 줄로 작성하세요.

```text
#세미나
제목: 시계열 예측 모델의 이해
발표일: 2026-09-22
요약: 최근 시계열 예측 모델의 구조와 실험 결과를 소개합니다.
```

- 첫 줄의 `#세미나`와 `제목:`, `발표일:`, `요약:`은 필수입니다. 불필요한 본문, 추가 필드 또는 코드 블록 기호를 붙이지 마세요. 안내의 네 줄만 복사합니다.
- 제목과 요약은 빈칸일 수 없습니다. 발표일은 실제 달력에 있는 `YYYY-MM-DD` 날짜여야 합니다.
- 파일을 하나 이상 직접 첨부해야 합니다. 외부 링크만 올리는 방식은 지원하지 않습니다.
- 제목은 180자, 요약은 1,000자 이내로 작성합니다. 파일은 메시지당 합계 100MiB 이내입니다.
- 기본 허용 파일은 PDF, PPT/PPTX, DOC/DOCX, XLS/XLSX, ZIP, TXT, MD, PNG/JPG/JPEG/WEBP입니다.
- 발표자는 **업로드한 사람의 Discord 서버 닉네임**으로 자동 입력됩니다. 서버 닉네임이 없으면 표시 이름 또는 계정 이름을 사용합니다. `발표자:` 필드를 따로 쓰지 마세요.
- 자료실은 **업로드 날짜가 최신인 순서**로 정렬됩니다. 발표일은 별도로 표시됩니다.

양식이 맞지 않는 메시지는 게시되지 않습니다. 거절 이유는 서버의 `logs/discord-sync.log`와 `discord-sync-state/rejected-*.json`에서 확인할 수 있습니다. 거절된 메시지를 수정하는 대신 양식을 고친 **새 메시지와 첨부파일**로 다시 올려주세요. 기존 메시지의 수정·삭제는 홈페이지에 자동 반영되지 않습니다.

## 잘못 올린 자료 삭제

1. 홈페이지의 **관리자** 링크 또는 `/admin.html`을 엽니다.
2. 관리자 비밀번호로 로그인한 뒤 **세미나 자료 관리**를 선택합니다.
3. 제목·발표자·파일명을 확인하고 **자료 삭제 → 삭제 확인**을 누릅니다.

확인한 자료와 첨부파일이 공개 홈페이지에서 제거되고 같은 원본은 다시 수집되지 않습니다. Discord 원본 메시지는 남아 있으므로 필요하면 Discord에서 별도로 삭제하세요. 서버 내부에는 복구를 위한 비공개 보관본이 `seminar-data/trash/`에 남습니다.

삭제 기능을 지원하지 않는다는 메시지가 나오면 화면만 업데이트된 상태일 수 있습니다. 위 절차로 패키지를 덮어쓰고 **06번 서버 창을 재실행**하세요. 관리자 비밀번호가 아직 없다면 기존 `08-SET-ADMIN-PASSWORD.bat`로 먼저 설정합니다.

## 한글이 표시되지 않을 때

페이지 상단의 언어 버튼이 **한국어**라면 현재 영어 화면입니다. 그 버튼을 누르면 한국어 화면으로 바뀝니다. 바로 한국어 화면을 열려면 `/seminars.html?lang=ko`로 접속하세요. 언어 선택은 브라우저에 기억됩니다.

업로드한 한국어 제목·요약·파일명은 그대로 지원합니다. 화면 언어를 바꿔도 자료의 원문을 자동 번역하지는 않습니다. 이전의 영문 화면과 파일명만 표시된 자료는 한글 미지원 때문이 아니라, 당시 언어 선택과 업로드 내용에 따른 표시였습니다.
