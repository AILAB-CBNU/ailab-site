# 구성원 사진·링크 관리

관리자 페이지에서 교수님, 현재 구성원, Alumni의 사진과 GitHub·LinkedIn·개인 웹사이트 링크를 수정할 수 있습니다. 공개 구성원 페이지에는 저장한 사진과 링크가 표시됩니다.

## 기존 Windows 서버에 업데이트 적용

11번 자동 업데이트와 12번 즉시 업데이트는 `site/` 화면 파일만 바꿉니다. **사진·링크 저장 기능은 아래 패키지를 서버 PC에 한 번 설치해야 동작합니다.**

1. 자동 업데이트를 사용 중이면 `13-STOP-AUTO-UPDATE.bat`를 실행해 잠시 해제합니다.
2. 실행 중인 **06번 홈페이지 서버 창과 10번 Discord 수집기 창을 닫습니다.** 설치 중에는 홈페이지와 수집이 잠시 중단됩니다.
3. `ailab-people-update-20260922.zip`을 **기존 프로젝트 폴더 안에** 압축 해제하고 같은 이름의 파일은 덮어씁니다. 압축 안의 `site`, `seminar_service`, `discord_sync`, `docs`가 기존 `06-START-HTTPS-WEBSITE.bat`와 같은 위치에 있어야 합니다.
4. `06-START-HTTPS-WEBSITE.bat`와 `10-START-DISCORD-SYNC.bat`를 다시 실행합니다.
5. 1번에서 자동 업데이트를 해제했다면 `11-INSTALL-AUTO-UPDATE.bat`를 실행해 다시 등록합니다.
6. 브라우저에서 `Ctrl + F5`를 누른 뒤 관리자 페이지에 **구성원 사진·링크** 메뉴가 나타나는지 확인합니다.

기존 Python 런타임을 그대로 사용하므로 Python이나 Docker를 새로 설치할 필요가 없습니다. 토큰·관리자 비밀번호·수집 체크포인트·기존 자료를 덮어쓰지 않으며, 09번 Discord 설정을 다시 실행할 필요도 없습니다. 이 패키지에는 이전 세미나 양식 검사와 자료 삭제 업데이트도 포함됩니다.

## 사진 올리기

1. 홈페이지 하단의 **관리자** 링크 또는 `/admin.html`로 접속해 로그인합니다. 비밀번호를 아직 설정하지 않았다면 서버에서 `08-SET-ADMIN-PASSWORD.bat`를 먼저 실행합니다.
2. **구성원 사진·링크**를 열고 교수님·현재 구성원·Alumni 중 수정할 사람을 선택합니다.
3. **새 사진 선택**에서 사진 파일을 고릅니다. 선택하면 변환 후 바로 업로드되므로 완료 안내가 나올 때까지 기다립니다. 얼굴이 가운데에 있는 사진을 사용하면 구성원 카드에서 보기 좋습니다.
4. 구성원 페이지를 새로고침해 사진을 확인합니다.

JPEG·PNG·WebP 파일을 지원하며 선택할 원본 파일은 10MiB 이하여야 합니다. 브라우저에서 긴 변을 최대 768픽셀로 줄여 PNG로 변환한 뒤 서버에 전송합니다. 서버가 받는 이미지 크기는 최대 2MiB입니다. 저장되지 않는 경우 화면의 오류 안내를 확인하거나 더 작은 사진을 선택합니다.

**등록한 사진 삭제**를 선택하면 기본 이미지로 돌아갑니다. 기본 사진이 없는 구성원은 이름을 이용한 기본 표시로 돌아갑니다.

## GitHub·LinkedIn·개인 웹사이트 링크

같은 사람의 편집 화면에서 GitHub, LinkedIn, 개인 홈페이지 주소를 입력하고 **링크 저장**을 누릅니다. 링크에는 `https://` 또는 `http://`로 시작하는 전체 주소를 입력합니다. 연결할 주소가 없으면 입력란을 비우고 저장합니다. 구성원 카드의 세 아이콘은 항상 표시되며 주소가 없는 아이콘은 비활성화됩니다.

사진과 링크는 공개 구성원 페이지에 노출되므로 방문자에게 보여줄 내용을 입력합니다. 한 사람을 수정해도 다른 사람의 사진과 링크는 바뀌지 않습니다.

## 저장 위치와 서버 이전

업로드한 사진과 링크 설정 JSON은 서버의 **`seminar-data/people/`** 아래에 저장됩니다. 공개 페이지에서 사진과 링크를 보여주지만, 이 서버 저장 폴더 자체를 GitHub나 업데이트 ZIP에 포함하지는 않습니다.

- 11/12번 홈페이지 업데이트 후에도 저장한 사진과 링크는 유지됩니다.
- 업데이트 패키지를 덮어써도 기존 `seminar-data/`는 유지됩니다.
- 서버를 옮기거나 복구할 때는 **`seminar-data/`를 별도로 백업**합니다. GitHub 저장소만 복사하면 서버에서 업로드한 사진과 링크 설정은 복구되지 않습니다.
- `seminar-data/`에는 세미나 자료와 관리자 설정도 있으므로 백업은 서버 관리자만 접근할 수 있는 곳에 보관합니다.

저장 기능을 지원하지 않는다는 메시지가 나오면 화면만 업데이트된 상태일 수 있습니다. 위 패키지를 설치한 뒤 **06번 서버를 재시작**합니다.
