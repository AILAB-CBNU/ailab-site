# 최신 연구실 소개 반영 · 2026-10-02

제공받은 2026 소프트웨어학부 오픈랩 소개 자료와 현재 운영 사이트의 공개 관리자 수정 내용을 반영했습니다.

- 연구 분야: 시계열 데이터, 적응형 AI, 피지컬 AI, AI 에이전트, 음성 인식.
- 지원 안내: 모집 여부와 지원 절차는 랩장 정선우(merrybad@chungbuk.ac.kr)에게 이메일 문의. QR 코드, 오픈채팅, 별도 상담란과 장비 소개는 추가하지 않았습니다.
- 기존 등록된 RLRC·VTS·산업 AI 에이전트 과제에 최신 수행 내용을 추가했습니다. 관리자가 등록한 구체적인 제목, 전체 사업 기간과 수행 기관을 보존했습니다. VTS의 기존 전체 기간은 2025–2029이며, 최신 자료의 수행 시작일 2026.04.01은 설명에 표시했습니다.
- 완료 과제: SW중심대학사업(2019–2024), Grand ICT 연구센터(2020–2023), 수소에너지 농업현장 활용 실증 및 적용 확대(2022–2023).
- 기존 구성원 이름과 과정, 졸업생 목록은 보존했습니다.

## 서버 PC 적용

1. `06-START-HTTPS-WEBSITE.bat`로 실행한 홈페이지 창을 종료합니다.
2. `ailab-research-update-20261002.zip`을 기존 프로젝트 폴더에 압축 해제하고 같은 이름의 파일을 덮어씁니다. ZIP 안의 `site`, `seminar_service` 등이 기존 폴더와 겹치는 위치입니다.
3. `06-START-HTTPS-WEBSITE.bat`를 다시 실행합니다. 필요하면 브라우저에서 Ctrl+F5로 새로고침합니다.

기존 `seminar-data`, 사진, 관리자 비밀번호, 디스코드·Teams 설정, API 키는 패키지에 포함되지 않으며 유지됩니다. 최신 ZIP에는 이전 세미나·구성원·갤러리·브리핑 코드 업데이트가 포함되어 있습니다. 이미 실행 중인 디스코드 봇의 설정을 바꿀 필요는 없습니다.

11번 또는 12번 자동 업데이트는 `site/`만 갱신합니다. 연구 분야와 기본 텍스트는 이 방식으로 반영되지만, 기존 서버의 관리자 과제 목록을 갱신하는 백엔드 변경은 이 ZIP을 한 번 적용해야 합니다.

## 기본값과 이후 수정

- 연구 분야·연구실 소개·지원 문의 이메일·구성원 기본 링크: `site/js/data.js`.
- 현재 관리자 텍스트·헤더·푸터·연락처 수정 내용을 보존한 기본값: `site/data/content-defaults.json`. 한국어와 영어를 각각 보존하며 관리자 편집기의 ‘기본값’도 이 내용을 기준으로 복원됩니다.
- 과제 기본 목록: `site/data/projects.json`. 기존 공개 과제 29건을 보존하고 완료 과제 3건을 추가했습니다.
- 기존 서버 과제 목록 갱신: `site/data/projects-refresh-20261002.json`. 서버에서 현재 과제 내용이 캡처 당시와 동일할 때만 변경하며, 그 이후의 관리자 수정 또는 삭제는 보존합니다. 적용 후 `seminar-data/catalog/research-defaults-20261002.applied.json`에 완료 여부를 기록해 삭제한 과제가 되살아나지 않도록 합니다.

이후 관리자 수정은 계속 서버의 `seminar-data/site-content-overrides.json`과 `seminar-data/catalog/projects.json`에 저장되어 기본값보다 우선합니다. 구성원·갤러리에서 올린 사진은 계속 서버에만 저장됩니다. 이번 기본값에는 공개된 GitHub·LinkedIn 링크만 포함하고 업로드 사진과 사진 경로는 포함하지 않았습니다.
