# Discord 세미나 자료 자동 등록

대상: CBNU AI LAB → 세미나-자료
채널 링크: https://discord.com/channels/<SERVER_ID>/<CHANNEL_ID>

## Windows 서버에서 실행

1. 최신 Discord/세미나 업데이트 패키지를 기존 홈페이지 프로젝트 폴더 안에 풀어주세요. `09-SETUP-DISCORD.bat`와 기존 `06-START-HTTPS-WEBSITE.bat`가 같은 폴더에 있어야 합니다.
2. 홈페이지 실행 창(06번)은 켜두세요.
3. Discord 개발자 포털 → AI Lab Seminar → 봇 → 토큰 초기화에서 직접 새 토큰을 발급하고 복사합니다. 기존 토큰을 보관하고 있다면 그것을 써도 됩니다.
4. `09-SETUP-DISCORD.bat` 실행 → Bot token에 붙여넣고 Enter. 입력 문자는 보이지 않습니다. 채널 질문에는 **세미나-자료 채널의 ID 또는 채널 링크를 직접 입력**합니다. 빈칸은 허용하지 않습니다.
5. `Setup complete` 확인 후 `10-START-DISCORD-SYNC.bat` 실행. `Collector ready`가 나오면 아래 양식과 파일을 **하나의 새 메시지**로 올리세요.
6. 약 15~20초 뒤 홈페이지 `/seminars.html`을 새로고침합니다. 서버 닉네임은 발표자, 메시지 작성 시각은 업로드 날짜로 저장됩니다. 서버 닉네임이 없으면 Discord 표시 이름/계정 이름을 사용합니다.

이미 봇이 설정된 서버는 업데이트 후 홈페이지 실행 창과 10번 수집기 창을 닫았다가 다시 실행하면 됩니다. 토큰을 다시 입력할 필요가 없습니다. **11/12번 홈페이지 자동 업데이트는 `site/`만 교체하므로 수집기와 삭제 API 변경은 업데이트 패키지도 설치해야 적용됩니다.**

Docker, Hyper-V, pip, 별도 Python 설치는 필요 없습니다. 기존 무설치 패키지의 runtime/python을 사용합니다. 추가 인바운드 포트 설정도 필요 없습니다. 학교망에서 Discord API/CDN으로 나가는 HTTPS는 허용되어야 합니다.

## 업로드 양식

아래 네 줄을 메시지 본문에 복사하고 내용을 바꾼 뒤, 같은 메시지에 PDF나 발표 파일을 첨부해 전송합니다. 코드 블록 표시용 백틱은 메시지에 넣지 않습니다.

```text
#세미나
제목: Transformer 기반 시계열 이상 탐지
발표일: 2026-09-22
요약: 논문의 핵심 방법과 실험 결과를 소개합니다.
```

- 첫 번째 빈 줄이 아닌 줄은 정확히 `#세미나`입니다.
- `제목`, `발표일`, `요약`은 각각 한 줄에 한 번씩 작성합니다. 세 항목 모두 필수이며 다른 항목이나 추가 설명 줄은 넣지 않습니다. 빈 줄은 허용합니다.
- 제목은 1~180자, 요약은 1~1,000자입니다. 발표일은 `YYYY-MM-DD` 형식의 실제 날짜입니다.
- 파일을 하나 이상 직접 첨부해야 합니다. 파일만 보내거나 링크만 적은 글은 등록하지 않습니다.
- 발표자 이름은 따로 적지 않습니다. 업로드한 사람의 Discord 서버 닉네임을 사용합니다.
- 한글 제목·요약·파일명·닉네임을 지원합니다. 홈페이지 오른쪽 위가 `한국어` 버튼이면 현재 영문 화면이므로 이 버튼을 눌러 한글로 바꿉니다. 원본 자료의 언어는 자동 번역하지 않습니다.
- 목록은 **업로드 날짜의 최신순**입니다. 발표일은 별도 정보로 표시하며 정렬 기준을 바꾸지 않습니다.

형식이 맞지 않으면 홈페이지에 올리지 않고 수집기 로그에 `FORMAT_…` 사유를 남깁니다. 다른 메시지의 수집은 계속됩니다. 잘못 보낸 메시지를 편집하는 대신 **양식을 고쳐 새 메시지로 다시 보내세요.** 봇이 Discord에 오류 답장을 보내지는 않습니다.

## 잘못 올라간 자료 삭제

1. 홈페이지 하단 `관리자` 링크로 들어가 로그인합니다. 비밀번호를 아직 정하지 않았다면 서버의 `08-SET-ADMIN-PASSWORD.bat`를 먼저 실행합니다.
2. `세미나 자료 관리`에서 제목·발표자·파일명을 확인합니다.
3. 해당 자료의 `자료 삭제` → `삭제 확인`을 누릅니다.

삭제하면 홈페이지 목록과 파일 주소에서 내려갑니다. Discord 원본 메시지는 그대로이며, Discord에서만 메시지를 지워도 홈페이지 자료는 삭제되지 않습니다. 같은 원본 메시지는 다시 수집해도 복구되지 않으므로 재등록하려면 새 메시지로 올립니다.

서버에는 복구용 사본을 `seminar-data/trash/`, 재수집 방지 기록을 `seminar-data/deleted/`에 보관합니다. 두 폴더는 공개 웹 폴더 밖에 있으며 GitHub·배포 ZIP에 포함되지 않습니다. 삭제 중 서버가 꺼져도 삭제 기록이 저장된 자료는 공개되지 않으며 다음 시작 때 나머지 정리를 마칩니다. 이전에 사용자가 다운로드한 사본까지 지워지지는 않습니다.

## 동작 범위

- 설정 완료 시점 이후 새 메시지의 직접 첨부파일만 수집합니다. 이미 있던 자료는 다시 업로드하세요. 설정을 다시 실행하면 수집 시작점도 현재 시점으로 변경됩니다.
- 일반 텍스트/공지 채널 한 개를 수집합니다. 포럼·스레드·DM, 외부 파일 링크는 지원하지 않습니다.
- 메시지 수정·삭제를 홈페이지에 반영하지 않습니다. 다운로드한 자료는 홈페이지 서버에 보관됩니다.
- 전체 첨부파일을 저장한 뒤 manifest를 발행합니다. 실패 시 재시도하고 재시작 후 마지막 처리 지점부터 이어갑니다.
- 홈페이지가 꺼져 있으면 inbox에 대기하고 홈페이지가 켜질 때 등록됩니다. 날짜 내림차순 정렬과 중복 방지는 기존 세미나 서비스를 사용합니다.
- 기본 허용 형식: PDF, PPT/PPTX, DOC/DOCX, XLS/XLSX, ZIP, TXT, MD, PNG/JPG/JPEG/WEBP. 메시지당 합계 100MiB. 양식 오류·허용하지 않는 형식·빈 파일·초과 파일은 건너뛰고 `discord-sync-state/rejected-*.json`에 기록합니다.
- REST 방식으로 수집하므로 Discord에서 봇이 오프라인으로 표시될 수 있습니다. 실행 창의 `Collector ready`, `logs/discord-sync.log`, 실제 홈페이지 등록 결과로 확인하세요.
- 서버 재부팅 후에는 06번과 10번을 다시 실행해야 합니다. 자동 시작 등록은 이 추가 패키지에 포함하지 않았습니다.

## 보관 및 문제 해결

토큰은 서버의 `discord-sync-state/config.json`에 저장됩니다. 이 폴더를 공유하거나 공개 웹 폴더 안에 옮기지 마세요. 배포 ZIP에는 토큰이 포함되지 않습니다.

- HTTP 401: 토큰을 확인하고 09번으로 다시 설정합니다.
- HTTP 403: 봇이 해당 채널을 볼 수 있고 메시지 기록을 읽을 수 있는지 채널 권한을 확인합니다.
- Message Content Intent 오류: 개발자 포털의 봇 페이지에서 해당 설정을 켜고 저장합니다.
- Queued만 나오고 홈페이지에 없음: 홈페이지 실행 여부와 `seminar-inbox/*.error.txt`를 확인합니다.
- 한 서버 PC에서 10번은 하나만 실행하세요. 중복 실행 시 로컬 포트 잠금으로 두 번째 프로그램을 중단합니다.
