# Discord 세미나 자료 자동 등록

CBNU AI LAB의 **세미나-자료** 채널에 파일을 올리면 봇이 **세미나 정보 입력** 버튼으로 답장합니다. 버튼을 눌러 제목·발표일·요약을 제출하면 홈페이지 자료실에 등록을 요청합니다.

## 구성원이 자료를 올리는 방법

1. **파일 올리기:** 세미나-자료 채널에 PDF나 발표 파일을 직접 첨부한 새 메시지를 보냅니다. 본문은 비워 두어도 됩니다.
2. **정보 입력:** 약 15초 이내에 도착하는 봇 답장의 **세미나 정보 입력** 버튼을 누릅니다. Discord 안에서 열리는 입력 창에 아래 정보를 작성합니다.
3. **제출:** 입력 창의 제출 버튼을 누르고 결과 안내를 확인합니다. 홈페이지 서버가 실행 중이면 잠시 후 `/seminars.html`을 새로고침해 확인할 수 있습니다.

| 입력 항목 | 형식 |
| --- | --- |
| 제목 | 1~180자 |
| 발표일 | 실제 날짜, `YYYY-MM-DD` (예: `2026-09-22`) |
| 요약 | 1~1,000자, 여러 줄 입력 가능 |

- 입력 버튼과 제출 기능은 **원본 파일을 올린 사람만** 사용할 수 있습니다.
- 발표자는 원본 업로더의 **Discord 서버 닉네임**입니다. 서버 닉네임이 없으면 표시 이름 또는 계정 이름을 사용합니다. 발표자 입력란은 따로 없습니다.
- 정렬 기준은 **원본 파일 메시지의 업로드 날짜**입니다. 입력 창을 제출한 시각이나 발표일로 정렬하지 않습니다.
- 필수 정보가 없거나 날짜가 잘못되면 게시하지 않습니다. 입력 창 또는 봇의 오류 안내를 확인하고 다시 입력하세요.
- 제출 완료 안내는 **등록 요청이 접수되었다는 뜻**입니다. 홈페이지가 꺼져 있으면 대기하며, 홈페이지 실행 후 자료실에 반영됩니다.
- 한글 제목·요약·파일명·닉네임을 지원합니다. 홈페이지 오른쪽 위가 `한국어` 버튼이면 현재 영문 화면이므로 이 버튼을 눌러 한글로 바꿉니다. 원본 내용을 자동 번역하지는 않습니다.

기본 허용 파일은 PDF, PPT/PPTX, DOC/DOCX, XLS/XLSX, ZIP, TXT, MD, PNG/JPG/JPEG/WEBP이며, **메시지당 합계 100MiB 이하**입니다. 파일은 하나 이상 직접 첨부해야 하며, 외부 파일 링크만 적은 글은 지원하지 않습니다.

## 기존 Windows 서버 업데이트

설치 절차는 [Discord 입력 창 업데이트 안내](discord-form-update-20260922.md)를 따릅니다. 이미 설정한 서버는 **09번을 다시 실행하거나 봇 토큰을 재발급할 필요가 없습니다.**

**11/12번 홈페이지 자동 업데이트는 `site/`만 교체합니다.** 이번 버튼·입력 창 기능은 새 Discord 업데이트 패키지를 서버 PC에 적용한 뒤 **06번 홈페이지와 10번 수집기**를 다시 실행해야 동작합니다.

10번 실행 파일은 새 메시지를 확인하는 수집기와 Discord 버튼·입력 창 요청을 받는 Gateway 연결을 함께 실행합니다. 필요한 WebSocket 모듈은 패키지에 포함되어 있으므로 **pip, 시스템 Python, Docker, Hyper-V를 새로 설치하지 않습니다.** Gateway는 서버에서 Discord로 나가는 연결을 사용하므로 추가 인바운드 포트는 필요하지 않습니다.

## 봇 설정과 권한 확인

기존에 초대한 봇에 다음 설정이 있어야 합니다.

1. Discord 서버의 **세미나-자료** 채널 권한에서 봇의 **채널 보기**, **메시지 기록 보기**, **메시지 보내기**를 허용합니다. 버튼 안내는 일반 메시지이므로 Embed Links 권한은 필요하지 않습니다.
2. [Discord 개발자 포털](https://discord.com/developers/applications)에서 해당 앱 → **Bot → Privileged Gateway Intents → Message Content Intent**를 켜고 저장합니다.
3. 같은 앱의 **General Information → Interactions Endpoint URL**은 **빈칸**으로 둡니다. 이 프로그램은 Gateway로 버튼·입력 창 요청을 받습니다.
4. 서버 PC에서 **10-START-DISCORD-SYNC.bat**를 실행합니다. 이전 10번 창이 남아 있으면 먼저 닫습니다.

봇을 **처음 설정하는 경우에만** `09-SETUP-DISCORD.bat`를 실행해 Bot token과 세미나-자료 채널 ID 또는 링크를 입력합니다. 입력한 토큰은 화면에 표시되지 않습니다. 설정을 다시 실행하면 수집 시작점이 현재 시점으로 바뀌므로 기존 서버의 업데이트 때는 09번을 실행하지 않습니다.

학교망에서 Discord API·첨부파일 CDN으로 나가는 HTTPS와 Discord Gateway로 나가는 WSS 연결이 허용되어야 합니다. Discord 봇이 온라인으로 보이더라도 홈페이지 게시 결과와 서버 로그까지 확인하세요.

## 메시지 양식으로 바로 등록하기

버튼 대신 아래 네 줄을 **각각 한 줄씩** 작성하고 파일을 같은 새 메시지에 첨부해 보내도 됩니다. 이 경우 입력 창 없이 유효한 양식을 바로 처리합니다. 코드 블록 표시용 백틱은 메시지에 넣지 않습니다.

```text
# 세미나
제목: Transformer 기반 시계열 이상 탐지
발표일: 2026-09-22
요약: 논문의 핵심 방법과 실험 결과를 소개합니다.
```

첫 줄은 `# 세미나`이며 기존 `#세미나`도 지원합니다. `제목`, `발표일`, `요약`은 각각 한 번씩 모두 필요합니다. 빈 줄은 허용하지만 추가 필드나 여러 줄 요약은 이 **본문 양식에서는** 허용하지 않습니다. 여러 줄 요약은 버튼의 입력 창을 사용하세요. 발표자는 본문 양식에서도 원본 업로더의 서버 닉네임입니다.

## 잘못 올라간 자료 삭제

1. 홈페이지 하단 **관리자** 링크로 들어가 로그인합니다. 비밀번호를 아직 정하지 않았다면 서버의 `08-SET-ADMIN-PASSWORD.bat`를 먼저 실행합니다.
2. **세미나 자료 관리**에서 제목·발표자·파일명을 확인합니다.
3. 해당 자료의 **자료 삭제 → 삭제 확인**을 누릅니다.

홈페이지 목록과 파일 주소에서 자료가 내려가며, 같은 원본은 다시 수집해도 복구되지 않습니다. Discord 원본 메시지는 그대로 남습니다. Discord에서 메시지만 지워도 홈페이지 자료는 삭제되지 않습니다. 내용을 고쳐 재등록하려면 새 메시지에 파일을 다시 올립니다.

복구용 사본은 `seminar-data/trash/`, 재수집 방지 기록은 `seminar-data/deleted/`에 저장됩니다. 이 서버 저장 폴더는 GitHub·배포 ZIP에 포함되지 않습니다.

## 동작 범위와 문제 해결

- 설정 시점 이후 새로 올라온 일반 텍스트/공지 채널 한 개의 직접 첨부파일을 처리합니다. 포럼·스레드·DM은 지원하지 않습니다.
- 이미 수집을 지나친 오래된 메시지에는 새 버튼이 자동으로 붙지 않습니다. 업데이트 후 새 메시지에 파일을 올려 확인하세요.
- 기존 Discord 메시지의 수정·삭제를 홈페이지에 자동 반영하지 않습니다.
- 홈페이지가 꺼져 있으면 `seminar-inbox/`에서 대기합니다. `Queued` 후 자료실에 없다면 06번 실행 상태와 `seminar-inbox/*.error.txt`를 확인하세요.
- **봇 답장이 없음:** 10번 실행 상태, 대상 채널, 메시지 보내기 권한, `logs/discord-sync.log`를 확인합니다.
- **버튼을 눌러도 입력 창이 안 열림:** 10번의 Gateway 연결 상태, Message Content Intent, 비어 있어야 하는 Interactions Endpoint URL, 서버의 외부 WSS 연결을 확인합니다.
- **HTTP 401:** 저장한 봇 토큰의 유효성을 확인합니다. 토큰이 바뀐 경우에만 09번으로 다시 설정합니다.
- **HTTP 403:** 봇의 해당 채널 보기·기록 보기·메시지 보내기 권한을 확인합니다.
- **파일 또는 날짜 오류:** 봇·입력 창의 안내와 수집기 로그를 확인합니다. 허용하지 않는 파일이나 용량 초과 파일은 게시하지 않습니다.
- 서버 재부팅 후에는 06번과 10번을 다시 실행합니다. 10번은 한 서버 PC에서 하나만 실행합니다.

토큰과 수집 상태는 `discord-sync-state/`에 저장됩니다. 서버 이전 시 기존 상태와 `seminar-data/`, `seminar-inbox/`를 별도로 보존합니다. 토큰과 서버 저장 폴더를 공개 웹 폴더나 GitHub에 올리지 마세요.

구현 참고: [Discord 메시지 API](https://docs.discord.com/developers/resources/message), [Discord Gateway](https://docs.discord.com/developers/events/gateway), [Interactions 수신과 응답](https://docs.discord.com/developers/interactions/receiving-and-responding).
