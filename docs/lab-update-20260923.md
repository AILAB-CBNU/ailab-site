# 연구실 홈페이지 업데이트 — 2026-09-23

이 ZIP은 기존 Windows 서버 설치에 덮어쓰는 누적 업데이트입니다. Python·Caddy 최초 설치용이 아닙니다. 기존 Discord 입력창 및 구성원 사진/링크 관리 업데이트도 포함합니다.

## 서버에 적용

1. 자동 업데이트가 실행 중이면 `13` 중지 파일로 잠시 중지합니다.
2. 실행 중인 홈페이지 `06`과 Discord `10` 창을 닫습니다.
3. ZIP을 임시 폴더에 압축 해제합니다. 안의 `site`, `seminar_service`, `discord_sync`, `docs` 폴더를 **기존 `06` BAT 파일이 있는 폴더**에 복사하고 같은 파일은 덮어씁니다.
4. 기존 `seminar-data`, `discord-sync-state`, 설정, Python, Caddy 폴더는 삭제하지 않습니다.
5. 기존 `06`과 `10`을 다시 실행합니다. 관리자 페이지와 홈페이지에서 `Ctrl+F5`로 새로고침합니다.
6. 이 업데이트가 GitHub에 반영된 것을 확인한 뒤 `11`로 자동 업데이트를 다시 켭니다. 반영 전 켜면 이전 웹 화면으로 되돌아갈 수 있습니다.

홈페이지 자동 업데이트는 `site/`만 교체합니다. 이번에는 서버 API가 추가되어 **ZIP 덮어쓰기와 `06` 재시작이 필요**합니다. Caddy/HTTPS와 봇 토큰은 다시 설정하지 않습니다.

## 관리자 사용법

- **과제 관리 → 새 과제 추가**: 한국어/영어 제목, 표시 연도, 진행 중/완료/예정, 연구 기간, 지원기관, 설명, 관련 링크 입력 후 등록합니다. 목록에서 항목을 선택하면 수정·삭제할 수 있습니다.
- **갤러리 → 사진 추가**: 제목, 촬영일, 설명과 사진을 등록합니다. JPEG/PNG/WebP, 입력 10MB 이하를 지원합니다. 브라우저에서 원본 비율을 유지해 긴 변 최대 1200px의 PNG로 변환하며 저장 파일은 최대 2MB입니다. 큰 이미지가 거절되면 크기를 줄여 다시 선택하세요.
- 제목은 한 언어만 입력해도 다른 언어 화면에서 대체 표시됩니다. 갤러리는 촬영일 최신순, 과제는 표시 연도 최신순입니다.
- 기존 논문 사사에서 가져온 연구 지원은 실제 과제 기간/진행 상태를 알 수 없어 ‘상태 미확인’으로 표시합니다. 관리자가 확인 후 바꿀 수 있습니다.
- 갤러리 사진은 홈페이지에 공개됩니다. 클릭하면 원본 비율의 큰 사진을 볼 수 있습니다.

## 서버 데이터 보관

- 과제: `seminar-data/catalog/projects.json`
- 갤러리: `seminar-data/catalog/gallery.json`, `seminar-data/gallery/photos/`
- 구성원 사진·링크: 기존 `seminar-data/people/`

이 데이터는 Git과 배포 ZIP에 포함하지 않습니다. 서버 백업은 `seminar-data` 전체를 별도로 보관하세요. 갤러리 삭제/사진 교체 시 이전 이미지 URL은 즉시 비공개 처리됩니다. 과제 최초 목록만 공개 `site/data/projects.json`에서 읽으며, 관리자 저장 이후에는 서버 목록을 사용합니다.

## 홈 스크롤 길이 조절

`site/css/styles.css`에서 `--hero-scroll-height`를 검색합니다.

```css
:root {
  --hero-scroll-height: 200svh;
  --hero-scroll-height-mobile: 170svh;
}
```

첫 번째는 PC, 두 번째는 모바일입니다. `100svh`는 화면 한 높이입니다. 10씩 늘리면 더 길어지고 줄이면 짧아집니다. 예: PC 190/모바일 160은 조금 짧게, PC 210/모바일 180은 조금 길게. 변경 후 Ctrl+F5로 확인하세요. 서버에서만 직접 고친 파일은 다음 자동 업데이트 때 덮어써질 수 있으므로 GitHub 소스에도 같은 값을 반영해야 합니다.

구성원·교수님 사진은 세로 3:4로 통일했습니다. 관리자 미리보기의 별도 페이지 동작은 유지했습니다.
